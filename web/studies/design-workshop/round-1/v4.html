Why a blockchain notices when you lie

No bank checks the ledger. A few simple rules do — and you can try every one of them right here, with a toy coin called powCoin.

1A hash is a fingerprint

SHA-256 turns any text into 64 hex characters.1 Alice pays Bob 0.25 gives 9856743d…; change one digit to 0.26 and you get 2b2cd2e6… — nothing alike.

2Work means searching

A block only counts if its hash starts with two zeros. You cannot steer a hash, so miners guess: add a number called the nonce, hash, check, repeat.

Try it on block #4. Nonce → 0080a3e8… 2 of 2 zeros

Lars found that number after 5,775 guesses. Minas was still at nonce 905 with dc80146e…, no zeros yet.2 Lars earns the 1.5625 powCoin reward.

3Blocks point backwards

Every block stores the hash of the one before it. Block #4 carries 00e61301…, the fingerprint of block #3, so the order is sealed into the data itself.

4Change one, break all after

Edit a single transaction in block #2 and its hash changes. Block #3 now points at a fingerprint that no longer exists, and so does every block after it. To hide the edit you would have to redo all that work — faster than everyone else.

1 256 bits, written as 64 hexadecimal characters. Same input, same output — always.

Difficulty 2 means roughly 1 hash in 256 qualifies (16 × 16). The target time is 10 s per block.

2 Lars ran at 11,133 hashes per second, Minas at 11,000. Close — luck decides most rounds.
